Instructions

1. 1. Setting Up Epic Online Services and Obtaining API Keys You'll need these keys to access the Services! If you have them already, then ignore this step Login to the Epic Games Dev Portal with an Epic Games Account Create a new Product Go to Product Settings -> Scroll down to clients -> Add a new Client Add a new Client Policy -> Name your Client Policy -> Set the Client Policy Type to Custom, enable Connect and Sessions and all of the sub policy things, then Save & Exit Add a new Client -> Name your Client -> Set the Client Policy to the Client Policy you just created, then Save & Exit (if you want to use the epic login, use http://127.0.0.1 for the redirect URL) Go to Epic Online Services -> Account Social -> Epic Account Service -> Create Application Permissions -> Select which one you like (or just set to all) -> Save changes Linked clients -> Select client -> Save changes Go to "Project Settings" -> Scroll down to your IDs Copy and paste all of your credentials into the EOS API Key Asset once your project is set up Use the "LIVE" sandbox and deployment IDs Do NOT use the DEV or STAGE! It will NOT work
2. Rewrite the EOS API Key Fill out all the SDK keys on the EOS API Key Asset, you can find them in the Epic Online Services Dev Portal (SDK -> SDK Credentials -> Get Credentials)
3. Building for Android Install the Android Module through Unity Hub In File -> Build Settings, switch platform to Android In Unity -> Edit -> Project Settings... -> Player -> Android -> Other Settings -> Identification set Minimum API Level to Android 6.0 'Marshmallow' (API Level 23) as required by the EOS Android SDK (Optional) Install Android Logcat through Package Manager to see logs when running on Android device over USB (Window -> Package Manager -> Packages: Unity Registry -> Android Logcat -> Install) then open with Alt+6 or Window -> Analysis -> Android Logcat
